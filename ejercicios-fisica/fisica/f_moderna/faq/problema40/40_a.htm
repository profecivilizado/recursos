Principio de Heisemberg

Cuando se midan a la vez la posición y el momento de una partícula, el producto de las indeterminaciones en dichas medidas tendrá que ser mayor que h/(2π). Es decir: cuanto mejor se conozca la posición peor se conocerá el momento.

El principio de Heisemberg confirma la dualidad onda-partícula y la imposibilidad de observarla simultáneamente. La posición define el aspecto corpuscular y el momento define el aspecto ondulatorio (λ = h/p), cuanto mejor se conozca un aspecto, peor se conocerá el otro

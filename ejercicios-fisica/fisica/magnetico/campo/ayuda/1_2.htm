Campo magnético creado por un elemento de corriente

Un elemento de corriente es un trozo de cable cuya longitud (dL) es muy muy muy pequeña. En este trozo de cable hay una cantidad de carga muy pequeña dq moviéndose con velocidad v. Esta carga puede considerarse puntual y aplicarle la fórmula del campo creado por una carga puntual:

$$d\vec{B}=\frac{\mu_0}{4\pi}\,\frac{dq}{r^2}\,(\vec{u}_v\times\vec{u}_r)$$

Esta fórmula equivale a:

$$d\vec{B}=\frac{\mu_0}{4\pi}\,\frac{I\,dL}{r^2}\,(\vec{u}_I\times\vec{u}_r)$$

I

Intensidad de corriente en el conductor

uI

Vector unitario con la dirección y sentido de la corriente

r

Vector de posición del punto donde se quiere calcular el campo que crea el elemento de corriente

Integrando el campo del elemento de corriente a lo largo de todo el crea sta formulita para todo el conductor se obtiene el campo que este crea.

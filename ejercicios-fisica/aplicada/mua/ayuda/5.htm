Relación entre tiempos

El primer móvil empieza a mo-verse

El primer móvil lleva moviéndo-se un tiempo Δt. Comienza el movimiento del segundo

Cuando el primer móvil lleva moviéndose un tiempo t el segundo móvil llevará movién-dose un tiempo t'. Entonces:

t = Δt + t'

t' = t - Δt

 

El móvil que sale más tarde circula menos tiempo

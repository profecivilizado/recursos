El calor que intercambia un gas viene dado por:

Q = n·c·ΔT

Un cambio de temperatura muy pequeño (Tiende a cero) es una diferencial de temperatura: dT.
Si el cambio de temperatura tiende a cero el calor intercambiado también tenderá a cero, será una diferencial: dQ

dQ = n·c·dT

c es el calor molar a presión o volumen constante

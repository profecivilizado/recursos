El shunt colocado desvía por él una parte de la corriente y deja 0.3 A para recorrer el amperímetro

Ecuación de nodo:

I = I0 + IS   (I0 = 0.3 A)  

Ecuación de malla:

0 = IS·R - I0·r   (r = 200 Ω, R = 50 Ω)

Combinando las dos ecuaciones resulta un sistema de incógnitas: I, IS

De acuerdo con este resultado por el shunt se desvían 1.2 A

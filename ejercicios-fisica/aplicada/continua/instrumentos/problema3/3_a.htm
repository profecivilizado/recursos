El galvanómetro del problema puede medir hasta 100 μA. Para que mida hasta 1 mA (1000 μA) hay que colocarle un shunt que desvie por él 900 μA dejando 100 μA para recorrer el galvanómetro

Ecuación de nodo:

I = I0 + IS   (I = 1000 μA, I0 = 100 μA)  

Ecuación de malla:

0 = IS·R - I0·r   (r = 150 Ω)

Combinando las dos ecuaciones resulta un sistema de incógnitas: R, IS

Choques
Cuando chocan dos cuerpos el momento lineal se conserva.
La conservación del momento lineal se aplica entre el instante inmediatamente anterior al choque y el inmediatamente posterior de esta forma se puede admitir que el sistema está aislado

Se aplica esta restricción para que se pueda considerar aislado el sistema a pesar de estar sometido a fuerzas exteriores (El pe-so de los cuerpos).
Las fuerzas de contacto que aparecen en un choque son mucho mayores que el peso y éste se puede despreciar

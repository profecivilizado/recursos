Forma binómica:
Se multiplican cada una de las componentes de uno de los com-plejos por cada una de las componentes del otro y se suman te-niendo en cuenta que j2 = -1

N* = 1 + j·3,   M* = -2 + j·4

N* + M* = 1·(-2) + 1·(j·4) + (j·3)·(-2) + (j·3)·(j·4)

N* x M* = -2 + j·4 - j·6 -12 = -14 - j·2

Forma módulo-argumental
Se multiplican los módulos y se suman los argumentos

N* = (5)0,72,   M* = (3)-0,25

N* x M* = (5·3)(0,72 - 0,25) = 120,47

Forma exponencial
Se aplican las reglas convencionales

N* = 5·ej·0,72,   M* = 3·e-j·0,25

N* x M* = (5·3)·ej(0,72 - 0,25) = 15·ej·0,47

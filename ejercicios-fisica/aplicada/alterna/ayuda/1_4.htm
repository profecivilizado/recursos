Cociente

Forma binómica:
Se expresa el cociente como una fracción, se multiplican nume-rador y denominador por el conjugado del denominador y se sim-plifica

Forma módulo-argumental
Se dividen los módulos y se restan los argumentos

N* = (9)0,72,   M* = (3)-0,25

N* : M* = (9 / 3)(0,72 + 0,25) = 30,97

Forma exponencial
Se aplican las reglas convencionales

N* = 9·ej·0,72,   M* = 3·e-j·0,25

N* : M* = (9 / 3)·ej(0,72 + 0,25) = 3·ej·0,97

Impedancia
A cada elemento de circuito se le puede asignar una impedancia compleja que describe su comportamiento.

Resistencia

Z* = (R + j 0) = (R) 0

Bobina

Z* = (0 + j L·ω) = (L·ω) π/2

Condensador

Z* = (0 - j 1 / C·ω) = (1 / C·ω) -π/2

La componente imaginaria de la impedancia se denomina reactancia (+: Inductiva, -: Capacitiva)

Cuando se utilizan intensidad y tensión complejas sirven las relaciones vistas para corriente continua sustituyendo la re-sistencia por la impedancia. Excepción: La fórmula de la po-tencia
